# Quartiles Plot
Script to generate a quartiles plot. The Iris dataset ([Anderson, 1935](https://wiki.irises.org/pub/Hist/Info1986SIGNA37/SIGNA_37.pdf); [Anderson, 1936](https://doi.org/10.2307/2394164); [Fisher, 1936](https://doi.org/10.1111/j.1469-1809.1936.tb02137.x)) and a custom label depicting Iris inheritance ([Lim et al, 2007](https://doi.org/10.1093/aob/mcm116)) are used for demonstration.

installation:

```bash
pip install -r requirements.txt
```

usage:

```bash
python quartiles_plot.py
```
